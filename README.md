# Tool Bunker Homebrew Tap

Homebrew formulas for command-line tools published by
[Tool Bunker](https://github.com/tool-bunker).

## Install Code Buster

```sh
brew install tool-bunker/tap/code-buster
```

Verify the installation:

```sh
cb version
```

Upgrade to the latest published formula:

```sh
brew update
brew upgrade code-buster
```

Code Buster currently supports Homebrew on:

- Apple Silicon macOS
- x86-64 Linux

Release notes and other installation methods are available in the
[Code Buster repository](https://github.com/tool-bunker/code-buster).
